# Серверна частина SportKids

Тут зберігається схема PostgreSQL для Supabase. Вона створює:

- справжній обліковий запис тренера та його приватний кабінет;
- профілі гравців у кабінеті тренера;
- оцінки 0–100, деталізовані критерії, тести, SMART-цілі та виконані виклики;
- приватне сховище для фото гравців;
- правила доступу: тренер працює лише зі своїми гравцями.

## Порядок підключення

1. Створіть проєкт у Supabase.
2. Встановіть Supabase CLI та увійдіть у свій акаунт.
3. Зв'яжіть локальну папку з вашим проєктом: `supabase link --project-ref ВАШ_ID`.
4. Застосуйте міграції по черзі: `20260915_sportkids.sql`, `20260915_player_app_state.sql`, `20260915_personal_coach_workspace.sql`.
5. У Supabase Authentication увімкніть вхід через email і пароль або magic link.
6. Створіть або відкрийте акаунт тренера. Його особистий робочий простір створиться автоматично; далі можна одразу додавати профілі гравців.

У сайті використовується лише publishable key — він безпечний для браузера, оскільки доступ обмежують правила RLS. Не додавайте secret/service_role key у `index.html`, JavaScript браузера або GitHub.
