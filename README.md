# SportKids — індивідуальний розвиток гравця

Односторінковий сайт українською для роботи тренера з індивідуальним планом футболіста.

Відкрийте `index.html` у браузері. У локальній демоверсії профіль, оцінки, тести, SMART-цілі та виклики зберігаються у браузері.

Сайт спирається на структуру наданої карти SportKids: 8 напрямів оцінювання, щотижневий ритм, місячний фокус і шкалу 0–100. Додано автоматичне визначення трьох пріоритетів, практичний банк вправ, критерії оцінювання з таблиці, кабінет тренера та перегляд прогресу для батьків із графіком.

## Папки для повноцінної версії

- `index.html`, `app.js`, `*.css`, `challenges.js` — поточний інтерфейс сайту.
- `supabase/migrations/` — база даних, приватний кабінет тренера та синхронізація профілів гравців.
- `supabase-config.js` і `cloud.js` — вхід за email, створення команди та синхронізація даних з Supabase.
- `supabase/README.md` — як підключити серверну частину.
- `docs/DEPLOYMENT.md` — як опублікувати сайт на Vercel і підключити домен.
- `.env.example` — назви потрібних змінних; справжні ключі зберігаються лише у вашому `.env.local` і Vercel.

Поточний інтерфейс ще працює через `localStorage`. Схема для реального запуску вже підготовлена; наступним кроком є підключення екранів до Supabase та екрана входу.
