# Публікація SportKids

## 1. Швидка демоверсія

Поточний сайт можна опублікувати як статичний: перетягніть всю папку проєкту на Vercel Drop. Це дасть посилання на демо, але дані все ще житимуть тільки в одному браузері.

## 2. Повноцінна версія

Для реального запуску потрібні три акаунти власника проєкту:

1. **Supabase** — база, входи та приватні фото.
2. **GitHub** — безпечна історія коду й автоматичні оновлення.
3. **Vercel** — публікація сайту, HTTPS і власний домен.

### Налаштування Supabase

1. Створіть проєкт у регіоні ЄС.
2. Застосуйте через SQL Editor файли `supabase/migrations/20260915_sportkids.sql`, а потім `supabase/migrations/20260915_player_app_state.sql`.
3. Увімкніть email/password або magic link у Authentication.
4. Скопіюйте **Project URL** та **publishable key** у локальний `.env.local`, створений з `.env.example`.
5. Ніколи не публікуйте secret/service_role key у браузері або репозиторії.

### Налаштування Vercel

1. Створіть приватний репозиторій GitHub із цією папкою.
2. Імпортуйте його у Vercel.
3. Додайте змінні середовища `SUPABASE_URL` і `SUPABASE_ANON_KEY` у налаштуваннях Vercel.
4. Підключіть домен, наприклад `sportkids.ua`.
5. Після кожної зміни коду Vercel автоматично оновлюватиме сайт за тією ж адресою.

## Що ще треба реалізувати перед запуском

Поточний інтерфейс уже має всі екрани, але використовує `localStorage`. Наступний етап — підключити ці екрани до Supabase: екран входу, створення організації, зв'язки «тренер—гравець—батьки», завантаження фото до приватного bucket та перенесення локальних даних у таблиці. До цього не завантажуйте реальні дані дітей у публічну демоверсію.
